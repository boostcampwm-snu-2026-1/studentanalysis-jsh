# 구현 단계

## 목적
설계 단계에서 합의한 내용을 실제 코드로 작성한다.

## 절차

설계 요약을 참고해 코드를 작성한다. 별도의 확인 없이 바로 구현에 들어간다.

구현 중 설계에서 다루지 않은 결정이 필요하다면:
- 사소한 것은 합리적인 판단으로 직접 결정하고 나중에 리뷰에서 설명한다
- 중요한 것은 잠깐 멈추고 사용자에게 물어본다

## 완료 조건
코드 작성이 끝났을 때 → workflow가 `review` 스킬을 발동한다
